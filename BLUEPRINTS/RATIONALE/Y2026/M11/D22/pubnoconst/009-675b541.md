## 1. Context & Motivation

Principia Axiom #1 establishes zero external runtime dependencies (`CGO_ENABLED=0`), and Axiom #2 dictates that minimalism is the core essence of our UX.

Book I ("On Cause") represents the foundational philosophical essay in Res Imperii. On `main`, it was served via `/book-i` with a generous, centered reading column and quiet navigation links. In `v2`, we reproduce this experience cleanly using Gomponents, `rawcontent/book-i.md` embedded via Go's standard `embed` directive, and `github.com/yuin/goldmark` (a 100% pure Go CommonMark parser with zero C toolchain dependencies).

---

## 2. Changes Made

### A. Raw Content & Embedding (`rawcontent/`)
- `rawcontent/book-i.md`: Restored the canonical Book I source essay.
- `rawcontent/booki.go`: Embeds `book-i.md` via `//go:embed book-i.md` as `var BookIMarkdown string`.

### B. View Component & Scoped CSS (`views/booki/`)
- `views/booki/booki.go`:
  - `RenderMarkdown()`: Parses `BookIMarkdown` into HTML using `goldmark.Convert`, safely omitting raw HTML to eliminate script injection. Results are cached with `sync.Once`.
  - `Page()`: Gomponents view laying out `.article-page`, `.book-article`, top/bottom `BackLink` controls, and `.book-content`.
- `views/booki/booki.css`: Scoped typography adhering to design tokens (`--font-serif`, `--heading-h1`, `--heading-h3`, `--space-header-top`, centered 42rem column, and blockquote styling). Served at `/views/booki/booki.css`.

### C. Shared Navigation (`views/layout/layout.go` & `assets/css/site.css`)
- `views/layout/layout.go`: Added `BackLink(href, label string) g.Node`.
- `assets/css/site.css`: Added `.back-link` and `.back-icon` classes. The icon is rendered with pure CSS (a circular indicator with an inner border chevron) without relying on any external icon libraries or SVGs.

### D. Routing & Tests (`routes/routes.go`, `routes/routes_test.go`)
- `routes/routes.go`:
  - Mounted `/views/booki/booki.css`.
  - Mounted `GET /book-i` rendering `booki.Page()`.
- `routes/routes_test.go`:
  - `TestBookIPage`: Asserts HTTP 200, stylesheet link, key essay sections ("On Cause", "Causal Succession", "Substance, Cosmos and Substrate"), and `BackLink` navigation.
  - `TestBookICSS`: Asserts stylesheet reachability and `Content-Type: text/css`.
