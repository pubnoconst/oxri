---

## 1. Context & Motivation

With the remote Turso database (`internal/db`) and loopback SSH authentication (`internal/auth`) established, Phase 5 brings the complete Journal publishing and curation system into `v2` using Gomponents, pure modern CSS, and vanilla JS:

1. **Awaiting Confirmation UI (`views/loading/`)**:
   - Under Principia Axiom #5 (*"The users are to never be treated as tech literate"*), mutating form submissions and automatic resubmissions display a calm, non-technical confirmation phrase (`"Confirming, please wait."`) animated with a smooth bell-curve character magnification wave (`loadingMagnifyWave`).
2. **Journal Catalog & Permalink (`views/journals/`)**:
   - Collage grid (`/journals`) with 280-character plain-text excerpts, tactile media mounting (`assets/js/journal-media.js`), search query filtering, Title-Cased tag pills, and authenticated batch management (select all, publish/unpublish/delete selected or all).
   - Full-entry permalink reading view (`/journals/{id}`) with Goldmark-rendered prose and inline administrative controls (Edit, Bookmark/Unbookmark, Publish/Unpublish, Delete).
3. **2-Column Journal Editor (`views/editor/`)**:
   - Symmetrical 50/50 compose & live preview cards (`/journals/new`, `/journals/{id}/edit`) with client-side character-set whitelisting (`assets/js/journal-editor.js`), Title Case tag auto-capitalization, tag autocomplete suggestions, and the confirmation overlay.
   - **Security Fix**: Public `GET /journals/new` now passes `isAuth` to `store.DistinctTags(ctx, isAuth)`, preventing unpublished draft tags from leaking to unauthenticated visitors.
4. **Make Room / Vacate-Space Flow (`views/journals/vacate.go`)**:
   - When creating or updating an entry exceeds the storage budget (`db.ErrQuotaExceeded`), the pending submission is stashed and the author is redirected to `/journals/vacate-space/`.
   - Provides both one-click prioritized **Make Room Automatically** (evicting unpublished drafts first, then un-bookmarked entries, oldest first) and manual checkbox selection with live byte progress bar (`assets/js/vacate-space.js`) and automatic entry resubmission once enough space is freed.
