## 1. Context & Motivation

1. **Page Transitions (Ease In / Ease Out)**:
   Under Principia Axiom #2 (*"Minimalism is the core essence of our UX"*), navigating between pages should feel calm and continuous rather than abrupt. Adding CSS `@view-transition { navigation: auto; }`, `::view-transition-old(root)` / `::view-transition-new(root)` keyframes, body entrance fade-in, and same-origin click transition feedback (`assets/js/navigation-feedback.js`) provides smooth ease-out and ease-in across all routes while respecting `prefers-reduced-motion`.
2. **Remote Turso Database (`internal/db`)**:
   Under Principia Axiom #1 (`CGO_ENABLED=0` static binary) and Axiom #3 (*"All Inputs are evil"*), the persistence layer connects exclusively to the remote Turso libSQL database (`TURSO_DATABASE_URL` and `TURSO_AUTH_TOKEN` loaded from external `../oxri-parent/db.env`), disallowing local disk database files while permitting ephemeral `:memory:` instances for deterministic unit tests via pure-Go `modernc.org/sqlite`.

---

## 2. Changes Made

### A. Smooth Page Transitions (`assets/css/site.css`, `assets/js/navigation-feedback.js`, `views/layout/layout.go`)
- Added `@view-transition { navigation: auto; }` and `::view-transition-old(root)` (160ms ease-out) / `::view-transition-new(root)` (220ms ease-in-out) in `assets/css/site.css`.
- Added universal `body` fade-in animation (`220ms ease-in-out both page-fade-in`) and `.navigation-leaving body` opacity transition so browsers with or without View Transitions API ease out on link click and ease in on arrival.
- Added `assets/js/navigation-feedback.js` to apply `.navigation-leaving` on same-origin navigation clicks and `.navigation-pending` breathing feedback if a response takes longer than 180ms, cleaning up automatically on `pageshow` (bfcache restore).

### B. Remote Turso Database & Schema Migrations (`internal/db/db.go`, `internal/db/env.go`)
- Pure-Go Turso connector (`github.com/tursodatabase/libsql-client-go/libsql`) and pure-Go in-memory test driver (`modernc.org/sqlite`).
- Rejects empty or `file:` URLs so local disk databases are never created.
- Transactional versioned schema migrations tracked in `schema_migrations` (`CurrentSchemaVersion = 2`), enforcing `published` column presence, Title Case tag normalization (`1..4` runes), and per-entry tag uniqueness (`tag1 != tag2`, etc.) at the SQLite DDL level.

### C. Input Whitelisting & Storage Quota (`internal/db/sanitize.go`, `internal/db/quota.go`)
- Character-set whitelisting (`ValidateMediaURLChars`, `ValidateTagChars`, `ValidateProseChars`, `SanitizeSearchQuery`): permits only printable ASCII URLs and English/Latin/Greek prose and tags; rejects emojis, zero-width/bidi spoofing characters, and control characters.
- Self-imposed 4.5 GB storage quota (`DefaultMaxStorageBytes = 4_500_000_000` or `TURSO_MAX_STORAGE_BYTES` from `db.env`).
- Prioritized automatic eviction (`PreviewAutoVacate`, `AutoVacateBytes`): evicts unpublished drafts first (oldest first), followed by published un-bookmarked entries (oldest first), while preserving published bookmarked entries.

### D. Server Startup Wiring (`cmd/server/main.go`, `routes/routes.go`)
- `cmd/server/main.go` loads `../oxri-parent/db.env`, opens the remote Turso connection with a 15s startup timeout, logs the active schema version and byte usage (`Connected to remote Turso database (schema v2, used ... / 4500000000 bytes)`), and wires `Store` into `routes.Config`.
