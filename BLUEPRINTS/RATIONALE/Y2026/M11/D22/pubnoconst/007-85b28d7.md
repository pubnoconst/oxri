## 1. Context & Motivation

Principia Axiom #3 states that *"All Inputs are evil"*, and Axiom #8 dictates *"Modularization & Type System Correctness: Make erroneous states unrepresentable"*.

In traditional web architectures, raw primitive types (`string`, `[]string`) are passed deeply into business logic, with repetitive `if input == ""` or `if strings.Contains(input, "..")` checks sprinkled ad-hoc across handler routes. In a complex application or under agentic maintenance, a missed check leads directly to SSRF, directory traversal, or persistent XSS.

Phase 2 replaces primitive obsession with strongly typed, opaque domain values that can **only** be constructed via validated parsing functions. Once an object of type `SafePath` or `MediaURL` exists, it is mathematically guaranteed to adhere to domain invariants.

---

## 2. Changes Made

### A. Opaque Domain Types (`internal/domain`)
1. **`MediaURL` (`media_url.go`)**:
   - Encapsulates HTTPS-only URLs with unexported fields.
   - Enforces `https` scheme strictly.
   - Disallows localhost, `.localhost`, `.local`, and private/internal IP ranges (RFC 1918, loopbacks `127.0.0.1`, `::1`, and link-local cloud metadata endpoints `169.254.169.254`), eliminating SSRF at the type boundary.
2. **`Tag` & `TagSet` (`tag.go`)**:
   - `Tag`: Strictly lowercase alphanumeric kebab-case (`^[a-z0-9]+(-[a-z0-9]+)*$`) bounded between 1 and 40 characters.
   - `TagSet`: Immutable collection of unique, sorted tags with deduplication and `Contains` search.
3. **`Prose` (`prose.go`)**:
   - Safe text representation that structurally rejects null bytes (`\x00`), normalizes line endings (`\r\n` to `\n`), trims trailing whitespace, and enforces configurable character limits.
4. **`SafePath` (`safepath.go`)**:
   - Single-segment relative slug bounded to `^[a-z0-9][a-z0-9_-]{0,79}$`.
   - Traversal characters (`/`, `\`, `..`, `:`, null bytes) fail parsing immediately, making directory traversal impossible.
5. **`ValidatedEntry` (`entry.go`)**:
   - Composite domain entity uniting `SafePath`, `TagSet`, `Prose`, `[]MediaURL`, and timestamp.
   - Fields are unexported; cannot be directly instantiated from outside `internal/domain` except via `NewValidatedEntry`, which enforces non-zero invariants.

### B. Capability Token (`AdminCap` in `capability.go`)
- Defines `AdminCap` with unexported fields and `_ [0]func()` to prevent literal construction and struct equality tricks.
- Provides `SetupCapMinter()`: A thread-safe, single-use initialization hook (`sync.Once`) that returns the sole `CapMinter` function in the entire process runtime. Any subsequent call returns `nil`.
- This ensures only `internal/auth` can mint `AdminCap` tokens upon verified cryptographic SSH challenge responses, and sensitive administrative server functions can require `AdminCap` as a required parameter.

### C. Comprehensive Unit Testing
- Added unit tests for each type:
  - `media_url_test.go`: Validates HTTPS parsing and SSRF rejections.
  - `tag_test.go`: Validates kebab-case constraints and set deduplication.
  - `prose_test.go`: Validates null byte rejection and length bounds.
  - `safepath_test.go`: Validates directory traversal and character restrictions.
  - `entry_test.go`: Validates entity integrity and uninitialized zero-state rejection.
  - `capability_test.go`: Validates single-minter security constraint.
