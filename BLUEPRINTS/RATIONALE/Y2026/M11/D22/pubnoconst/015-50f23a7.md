Addresses all database integration, data-integrity, domain-persistence boundary, and file-decomposition findings from the architectural audit.

#### Summary
1. **Unified Domain-Persistence Boundary (\internal/domain/journal.go\, \internal/db/validation.go\, \outes/journals.go\)**:
   - Introduces opaque \domain.ValidatedJournalEntry\ and \domain.ParseJournalEntry\ in \internal/domain\ as the single canonical source of truth for character-set whitelists, SSRF host checks, Title Case tag normalization, per-entry tag uniqueness, and length bounds.
   - \internal/db\ delegates validation directly to \internal/domain\ and exposes \CreateValidated\ / \UpdateValidated\ consumed by \outes/journals.go\.
2. **Quota Enforced on Empty Databases & Single-Entry Updates (Audit 3.A)**:
   - Removed the \if used <= 0 { return nil }\ and \if otherBytes <= 0 { return nil }\ early returns in \checkQuotaForCreateTx\ and \checkQuotaForUpdateTx\, ensuring projected usage is always checked against \MaxStorageBytes\.
3. **Atomic Transactional Quota Enforcement (Audit 3.B)**:
   - \CreateValidated\ and \UpdateValidated\ execute quota checks and \INSERT\/\UPDATE\ inside an explicit SQLite transaction (\s.db.BeginTx\) serialized by \s.writeMu\, preventing concurrent requests from racing past the storage limit.
4. **Exact UTF-8 Byte Parity Between Go and SQLite (Audit 3.C)**:
   - Updated \usedStorageBytesSQL\ to use \length(CAST(col AS BLOB))\ instead of \length(col)\, measuring exact UTF-8 byte length rather than character counts and matching Go's \len(str)\ 1-for-1 for multi-byte accented Latin (\Rōma\) and Greek (\Λόγος\).
5. **Atomic Transactional Automatic Eviction (Audit 3.D)**:
   - \AutoVacateBytes\ computes the eviction candidate plan (\previewAutoVacateTx\) and deletes the candidate IDs (\deleteTx\) inside a single atomic database transaction.
6. **Modular Decomposition of \internal/db/\ (Audit 5 / Principia #8)**:
   - Replaced the 687-line monolithic \internal/db/db.go\ with focused single-responsibility files: \store.go\, \schema.go\, \alidation.go\, \journal.go\, \query.go\, \quota.go\, \sanitize.go\, and \env.go\.
7. **Adversarial & Concurrency Tests (\internal/db/db_test.go\)**:
   - Added \TestQuotaEnforcedOnEmptyDatabaseAndSingleEntryUpdate\, \TestMultiByteUTF8LatinAndGreekByteEstimationMatchesSQLite\, and \TestConcurrentCreatesNeverExceedQuota\.
