## Context

After the dead-code pass (063) the owner said JS and CSS "are not compile time checked and that bothers me", then chose plan step 6: "type-checking the JS in CI sounds good. I heard that jsdoc does this."

JSDoc is only the comment syntax for types (`/** @param {string} url */`); TypeScript's `tsc` does the checking. The scripts stay plain `.js`, with no build step, and the browser gets exactly the files in `assets/js/`.

## What changed

- **`tsconfig.json`**: `allowJs`, `checkJs`, `noEmit`, `strict`, `noUnusedLocals`, `noUnusedParameters`, `noImplicitReturns`, `noFallthroughCasesInSwitch`, `allowUnreachableCode: false`. It covers `assets/js/*.js` but not the vendored `*.min.js`.
- **`assets/types/globals.d.ts`**: the shared globals (`ResImperiiDots`, `ResImperiiMedia`, `ResImperiiLoading`) and the parts of `twttr`, markdown-it and DOMPurify the scripts call. `DotMotion` is a string union, so a misspelled motion is a type error. Only `tsc` reads the file; it isn't embedded or served.
- **Tooling**: TypeScript 5.6.3 is pinned in `package.json` as a devDependency. `.dockerignore` keeps `node_modules/`, the npm files, `tsconfig.json` and `assets/types/` out of the image.
- **CI**: Node 22, `npm ci`, then `tsc -p .`, before the binary build. Locally it's `mage typecheck`, and `mage check` runs Test, Typecheck and Build.
- **Annotations**: 195 strict errors fixed, now 0. Mostly element types for `getElementById`, typed parameters, and WebAuthn response types. A few small logic tightenings:
  - `journal-editor.js` resolves its required elements once through `requiredElements()`, so they're non-null.
  - The lazy-embed IntersectionObserver uses its own callback argument.
  - Errors are read through `instanceof Error`.
  - Link and double-click handlers check element types before using them.

## Why

"Diligence can betray you, type system won't." The JS contract test (063) checks the names shared between scripts, and `tsc` now checks what happens inside each script too: wrong properties, null elements, misspelled members.
