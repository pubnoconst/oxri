## Context

After "stable beats peak" (074), the owner asked Claude to self-host the fonts and explore Chrome profiling.

Claude's first write-up recorded desktop paint timings from one warm tab. The owner rejected it: "there's no evidence here of measured field performance or repeatable mobile-browser profiling", and pointed to Google's Core Web Vitals and their "good" thresholds (LCP < 2.5 s, INP < 200 ms, CLS < 0.1).

The owner then chose, in order:
1. "migrate", to run the test server on real data;
2. a CI performance test;
3. later, an endpoint that logs ongoing performance against the standard (the next PR).

## What changed

**Fonts** (`assets/fonts.go`, `assets/fonts/`):
- The five OFL families are Google Fonts' own subsets, served from the site with content-hashed URLs and their licences beside them. `fonts.css` is generated. The CSP allows only `'self'` for fonts and styles.
- Each role is one family assembled by `unicode-range`. All Greek in the sans roles comes from Didact Gothic, so a phrase no longer changes face midway.
- Each role has a chain of fallback faces, one per system font family, each measured against that font: Georgia, Times New Roman (= Liberation Serif), Noto Serif; Arial (= Helvetica, Liberation Sans), Roboto. The role stacks are generated with the faces.
- No preload. Every face uses `font-display: swap`.

**Field data**:
- Vendored `web-vitals` 6.2.3 (Apache-2.0). `vitals.js` sends LCP, INP, CLS and TTFB when the page becomes hidden, to `POST /vitals` (`routes/vitals.go`).
- Schema v9 adds the `vitals` table, bounded to 28 days and 20,000 rows, outside the writing quota.
- It stores only the route template, value, server-side rating, device class, connection type, memory class and the blamed selector.
- It skips the admin's views and loopback hosts, and is rate-limited with a 4 KB cap.
- Settings → Field Performance shows the p75 of each metric, mobile first.

**Lab** (`cmd/lab`, `mage lab`):
- Headless Chrome emulating a budget phone with Lighthouse's mobile defaults; a fresh profile per run; scripted taps and typing.
- Each page reports the median ± spread (worst run).
- Flags: `-beacon` (the field report is complete), `-local` (a seeded in-memory site, no credentials), `-budget` (Google's good lines), `-debug` (timeline).

**CI**: a `performance` job runs `-local -beacon`, then `-local -runs 5 -budget`. The table goes to the job summary and is kept as an artifact.

- **What fails the build:** an incomplete field report or a layout shift (CLS over 0.1 on any run), because those are deterministic.
- **What is only reported:** LCP and INP against Google's lines. On the shared runner `/journals` swung between passing (median 2,472 ms) and failing (2,544 ms), with 1.1 s TTFB spikes, so a timing gate would fail pull requests at random. The owner asked to pull back from heavier tooling ("Do we need APM? … Is it over?"), and agreed: optimise, ship, then benchmark against real data.

## What the evidence showed

Lab, 5 runs per page (10 on `/journals`), real data, signed out. Google Fonts → self-hosted:

| Page | LCP | Worst CLS |
|---|---|---|
| `/` | 1168 ± 160 → 1180 ± 44 ms | 0 → 0 |
| `/book-i` | 1540 ± 764 → 1284 ± 80 ms | 0.166 → 0 |
| `/journals` | 2034 ± 196 → 2032 ± 264 ms | 0.006 → 0 |
| `/login` | 1376 ± 360 → 1120 ± 76 ms | 0 → 0 |

**Four regressions were caught before shipping:**
1. **A preloaded font held text back.** With the UI font preloaded, `/login`'s text appeared at about 4.6 s in every run, against 1.12 s without the preload.
2. **Fallback faces without `font-display`** defaulted to blocking text.
3. **Field reports would have carried TTFB only.** They were sent on `pagehide`, which Chrome fires before `web-vitals` finalises LCP, CLS and INP on `visibilitychange`.
4. **The book's fallback was tuned to Georgia only.** The first CI run on Ubuntu, which has no Georgia, measured CLS 0.194 on every `/book-i` run. Android lacks Georgia and Arial too.

## Not done / risk

- **`/journals` sits at the line in the emulated budget phone** (median LCP about 2.4 to 2.5 s; every other page is about 1.2 to 1.5 s). Next: `mage benchmark` against real data, then find the bottleneck and brainstorm the fix.
- **The boot log is dropped.** Field TTFB covers what cold starts cost readers.
- **Android fallbacks are unproven on a phone.** The Roboto and Noto Serif metrics come from Google Fonts' copies; Android's `local()` names are matched by name.
- **Local tests could not run for the second commit.** Windows Defender quarantined Go's linker on the dev machine. CI (Linux) ran the full suite and the lab.
