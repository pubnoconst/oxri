## Context

The owner asked to "change the quote text from happy monkey to Short Stack". On shipping, they added: "please freeze the entry cards, I quite like that I can edit, publish, bookmark and delete a journal without going into it."

## What changed

**Short Stack** sets quoted matter: tweet clippings, Bible passages and blockquotes in entries.
- It is Google Fonts' Latin subset (24 kB) with its OFL licence. Happy Monkey's two files and licence are removed.
- Short Stack has no extended-Latin or Greek subset. Greek still comes from Didact Gothic, so the role is unchanged there. Extended-Latin letters in a quote fall to the measured system fallback.
- The fallbacks were re-measured against Short Stack: Arial 126.8 % (ascent 73.4, descent 23.7) and Roboto 128.7 % (72.3, 23.3). A test paragraph takes the same height in the matched fallback and in Short Stack (140 px and 140 px).

**The entry cards are frozen** (HIG §4). Signed in, each catalog card's footer carries Edit, Bookmark/Unbookmark, Publish/Unpublish and Delete, whose prompt opens in place. Every action but Edit returns to the same catalog page, keeping its search, tags and page. Readers see none of them. `TestCatalogCardsKeepTheirActions` checks the controls on the author's cards and that readers don't see them. It runs each action and checks it took effect and returned to the page it came from. Pointing the card's Bookmark form at a wrong URL made it fail, as it should.

**The lab's `-beacon` check** now prints the element blamed for LCP and for a layout shift.

## Trade-offs

- **Short Stack is about 15 % wider** than Happy Monkey: the same quote ran 140 px against 116 px. Quotes are longer, and clippings taller.
- **CLS on `/journals`** moved from 0 to about 0.008 in the lab. The blamed element is an excerpt below a quote: the fallback matches Short Stack's width on average, but a given quote can wrap one more line once the web font arrives. That is well inside Google's 0.1 and the CI gate. Measuring the fallback against real quote text could bring it back to zero.
