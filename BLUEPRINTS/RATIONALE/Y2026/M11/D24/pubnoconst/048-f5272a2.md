## Owner's request

"Remove the tag name placeholders. Just say provide tag names separated by a comma. Also generate a HIG.md where UI language is described."

## Decision

- **Tags placeholder:** "Log, Dev, Note" became "Tag names, separated by commas".
  - Example values in a placeholder read as real data (or as defaults); a placeholder should say what to type.
  - The "Suggestions:" pills under the field list tags that really exist, so they stay.
  - This became a rule in the HIG: placeholders hold instructions, not example data.
- **`BLUEPRINTS/HIG.md`** describes how the site looks, moves and speaks, so new screens stay consistent without re-deriving it from the code each time:
  - principles, with the Galaxy A02s as the reference device;
  - typography (one serif family, monospace for figures), colour tokens for both themes, and the rule that accents mean state only;
  - surfaces, space and radii;
  - controls: the three button ranks (at most one encouraged button per view, labels are verbs), the form-field anatomy (label + counter, input with `maxlength` from Go, hint, live error), tag rules, back links and pagination;
  - the dot-matrix loading language from RATIONALE 047: puzzle for working on your action, twinkle for downloading, comet for your turn, with labels and placement, and never a placeholder box;
  - motion: FLIP arrivals at 460 ms, page transitions at 160 / 220 ms, interrupted motion continuing from its visible state, reduced motion;
  - voice and copy, accessibility, performance as design, and a new-screen checklist.
- **Written from the code, and honest about gaps.** "Known inconsistencies to align" lists three things that aren't fixed here:
  - two editor messages that start "Required:";
  - formal error-page wording ("payload exceeds the permitted size limit");
  - buttons that rely on the browser's default focus ring.
- **Linked from** `NEXT.md` (Principles) and the README (Design Language).
