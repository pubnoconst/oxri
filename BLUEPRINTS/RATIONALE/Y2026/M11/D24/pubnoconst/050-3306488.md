## Set aside: faint dark text after theme toggles

The owner reported that after toggling light and dark a few times, journal cards that contain tweets show faint dark text in light mode. They then set it aside. `NEXT.md` records it so it isn't lost.

**Tested in Chrome on the local server, not reproduced:**
- theme set in code: once, 5× at 0.7 s, 6× at 0.4 s;
- five real background double-clicks while tweets were still loading.

**Every time:**
- all tweets were rebuilt with `theme=light`;
- the card text colour was `rgb(52, 51, 47)`, and the only partial opacity was the excerpt's designed 0.88;
- a fixed card patch looked pixel-identical before and after toggling.

**To resume:** the owner's screenshot, the browser, and whether the faint text is inside the tweet or in the entry's own text.

**Suspects:**
- another browser, likely Edge, which already behaves differently with tweets;
- the light linen weave reading as faint text in tall, stretched cards. That happens on a fresh load too, so it's less likely.
