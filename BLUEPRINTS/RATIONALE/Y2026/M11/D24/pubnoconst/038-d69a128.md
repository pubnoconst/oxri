## Why

Dead code is a maintenance trap: it reads as live, it gets "fixed" while the real path stays broken (RATIONALE 035 found exactly that with a diverged `.env` loader), and it misleads anyone reading the code for the first time. The owner asked for all of it, and every dead branch, to go.

## How it was found

The `golang.org/x/tools/cmd/deadcode` tool would have needed a download, so throwaway scans were used instead:
- **Go:** every top-level declaration (functions, methods, types, vars, consts) in non-test files, counted against references in non-test code.
- **CSS:** classes not used by any Go view or JS; `@keyframes` never named by an animation; custom properties never read with `var()` or `setProperty`.
- **JS:** functions never referenced.
- **Assets:** typed handles no view loads.

Every candidate was then verified by hand, because text scans can't see dynamic use.

## Removed

- **Go:**
  - `auth.ErrChallengeExpired`, `ErrChallengeNotFound`, `ErrInvalidBinding`: left over from the 30-second confirm flow removed in PR #30.
  - `auth.ErrPasskeyUnsupported`, `domain.ErrInvalidProse`, `serverfns.ErrInvalidRedirect`: declared, never returned or checked.
- **JS (`water-ripple.js`):** the "reuse an existing inline SVG filter" path (`opts.filter`, `opts.useClass`, `#wr-img-N` / `#wr-disp-N` lookup, `.is-submerged`, `#water-surface-refract`) served only the removed confirm page. Every caller now gets an owned dynamic filter, so `attach()` has a single path.
- **CSS:**
  - `.tweet-fallback-card.is-loading` and its `@keyframes media-loading-breathe` (nothing ever adds `is-loading`);
  - `.vacate-entry-raw-bytes`;
  - `.method-actions` and its mobile rule;
  - a stale "Footer / Notice" comment.

## Kept on purpose (false positives)

- The `pilotWebAuthnUser` methods `WebAuthnID`, `WebAuthnName`, `WebAuthnDisplayName`, `WebAuthnCredentials`: they implement `go-webauthn`'s `User` interface and the library calls them.
- `.twitter-tweet` and `.htmx-swapping`: added at runtime by Twitter's `widgets.js` and by HTMX.

## Branches

- Deleted local `v2-touch-ripple`, superseded by PR #36. Before force-deleting, its content was diffed against `main`: the only lines missing were the ones the governor deliberately replaced.
- Deleted local `v2-quick-wins` (merged; its remote copy was already gone).
- Fast-forwarded the stale local copies of `prod` and `v2` to their remotes.
- **Kept** `v1`, `fsharp-legacy` and `rust-experiment`: the archived lineage documented in the README. They are unmerged by design, not dead.
