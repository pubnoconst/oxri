## Context

The owner asked for a UI/UX review. One finding was that the signed-out Journals header showed "Add new entry" next to "Author sign in", offering readers an action they can't take. Following the link led to the editor's sign-in prompt. The owner: "Users shouldn't see add new entry button if not logged in. Fix and ship it."

## Decision

- `renderJournalsHeader` renders "Add new entry" only when the author is signed in. Signed out, the header offers only "Author sign in".
- `/journals/new` itself is unchanged: it still sends a signed-out visitor to sign in, for anyone who has the URL.
- No other public link to `/journals/new` exists. The editor's own "Sign in" prompt is reached only from that page.

## Verification

- **New test `TestNewEntryLinkOnlyForAuthor`:**
  - signed out, the catalog contains no "Add new entry" and no `/journals/new` link, but keeps "Author sign in";
  - signed in, it shows "Add new entry".
- vet and `CGO_ENABLED=0 go test -count=1 ./...` pass.
