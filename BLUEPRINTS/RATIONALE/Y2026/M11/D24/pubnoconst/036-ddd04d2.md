## Problem

The maintainability review (RATIONALE 035) found that **passkey sign-in, the owner's primary way in, had 0% test coverage** (`BeginPasskeyLogin`, `FinishPasskeyLogin`, `FinishPasskeyRegistration`). The password+TOTP fallback was thoroughly tested; the path actually used was not. A `go-webauthn` upgrade or a refactor could have broken sign-in while CI stayed green.

## Decision

- **A minimal software authenticator, written in test code.** It holds one P-256 credential, returns `none` attestation, sets the user-present and user-verified flags, and keeps a signature counter. Registration emits a CBOR attestation object with a COSE EC2 public key. Sign-in signs `authenticatorData ‖ SHA-256(clientDataJSON)` with ES256 (ASN.1 DER), exactly as a real device does.
- **It drives the real routes**, not internal functions, with the same JSON `passkey.js` posts. The test therefore exercises the routing, cookies, CSRF headers, capability gating (`freshAdminOnly`), storage, and `go-webauthn` verification together.
- **Forgeries are tested as carefully as success.** Each must fail *without a session*, and the server log was checked to confirm each fails for its own reason. A test that passes for the wrong reason is worse than a failing one.
  - Replayed assertion: "ceremony not found or expired" (ceremonies are single-use).
  - Signature by a different key: "Error validating the assertion signature".
  - Phishing origin relaying the challenge: "Error validating origin".
  - Cloned authenticator (counter ≤ stored): "authenticator appears to be cloned".
- **No new dependency.** CBOR encoding uses `fxamacker/cbor`, which `go-webauthn` already links into the binary. `go.mod` only drops its `// indirect` marker. A dedicated virtual-authenticator library was considered and rejected as an unnecessary dependency.

## Result

- Passkey core coverage: `consumeWebAuthnCeremony` 88.9%, `FinishPasskeyLogin` 87.5%, `FinishPasskeyRegistration` 72.7%, `BeginPasskeyLogin` 69.2% (all from 0%).
- Total statement coverage (cross-package): **63.7% → 68.1%**.
