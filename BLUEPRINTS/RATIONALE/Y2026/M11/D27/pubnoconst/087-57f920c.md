## Context

In `086` (`19aeb9c`), floating a compressed `≤ 140`-character quote beside a taller lead-in sentence + `<pre><code>` block (`Rule D1`) left an L-shaped void under the quote card because a CSS float keeps its intrinsic height while the code block beside it runs lower. The owner refined `Rule D1`: *"the preview card in D1 should match the height of the code block and the contents should go in the center of that card."*

## What changed

- **Prototype (`card-preview-ideas`, tag `newspaper-entry-v1` updated to `a6bd1c5`):** `wrap-compact-code` now pairs the compressed top-left source card (`clamp(12.5rem, 29%, 15.25rem)`) and the opening prose + first `<pre><code>` block (`~71%`) inside a two-column stretched grid (`align-items: stretch`). The source card's bottom aligns flush with the bottom of `<pre><code>` (`0 px` offset in both `D1` and `D2`), its contents sit centred vertically inside the card (`justify-content: center`), and any prose after that code block spans `100%` width below.
